# Privacy Policy for Titleless

Effective date: 30 August 2026

Titleless does not collect, transmit, sell, or share personal information, browsing history, or website content.

## Local storage

Titleless stores one setting in Chrome's local extension storage: whether title hiding is on or off. Chrome keeps this setting on the user's device. Titleless does not send it to the developer or any third party.

## Reddit access

Titleless runs packaged CSS and JavaScript on Reddit pages to hide post-title elements. It does not read, record, store, or transmit Reddit page content, account information, browsing history, or user activity.

## External services

Titleless uses no analytics, advertising, remote code, or external services.

## Changes

Any future release that changes these practices will update this policy before publication.
